# InvertirOnline (IOL) MCP Server Tools Definition

Definición de herramientas MCP para InvertirOnline (https://mcp.invertironline.com/).

## Herramientas disponibles:
- `iol_get_cuenta`: Consulta saldos en ARS/USD y valorizado total.
- `iol_get_portafolio`: Obtiene tenencias de CEDEARs, acciones BYMA, bonos y ONs.
- `iol_get_cotizacion`: Cotización en tiempo real de activos en BYMA.
- `iol_get_operaciones`: Historial de operaciones de la cuenta comitente.
